## Requisitos funcionais
| Requisitos | Função | Descrição |
| --- | --- | --- |
| RF01 | Cadastro de usuários | Permitir o cadastro de usuários por meio de e-mail e senha. |
| RF02 | Login | Permitir que usuários cadastrados acessem o sistema por meio de suas credenciais. |
| RF03 | Logout | Permitir que o usuário encerre sua sessão. |
| RF04 | Cadastro de partituras | Permitir o registro de informações sobre as partituras, como título, compositor, ano de composição, gênero, instrumentação, tonalidade e descrição. |
| RF05 | Listagem de partituras | Apresentar as partituras cadastradas no acervo. |
| RF06 | Pesquisa de partituras | Permitir a pesquisa de partituras pelo título ou nome do compositor. |
| RF07 | Consulta de detalhes | Apresentar as informações cadastradas de uma partitura específica. |
| RF08 | Atualização de registros | Permitir a alteração dos dados de uma partitura cadastrada. |
| RF09 | Exclusão de registros | Permitir a exclusão de uma partitura do banco de dados. |
| RF10 | Acesso aos arquivos digitais | Permitir a abertura dos arquivos PDF associados às partituras cadastradas. |
| RF11 | Registro de direitos autorais | Permitir o armazenamento da situação dos direitos de utilização e de informações sobre o titular da licença, quando aplicável. |
